# Reserved. – Webseite

Statische One-Page-Webseite für **Reserved. – Social Media für lokale Unternehmen**.

## Struktur
```
index.html            Seite (Hero, Warum, Leistungen, Ablauf, Pakete, Instagram-Feed, Feedback, Über uns, Kontakt, Impressum)
assets/css/style.css  Design (Brand-Farben & Schriften)
assets/js/main.js     Interaktionen (Story-Slider, Feed-Karussell, Feedback-Filter, Paket-Umschalter, Formular → E-Mail)
assets/fonts/         Cormorant Garamond, Inter, Pinyon Script – lokal gehostet (DSGVO, kein Google-Fonts-Request)
assets/img/           Instagram-Posts als WebP
```

## Farben
Creme #F4F1EA · Sand #EFE9DC · Terrakotta #B8593F · Kohle #2B2622 · Hellblau #A9BFD4 · Rostbraun #984619 · Mokka #6B4A3A · Warmgrau #7A7269 · Trennlinie #DCD5C8

## Vor dem Livegang
- Vollständige Datenschutzerklärung im `<dialog id="datenschutz">` einfügen
- Preise der Pakete ergänzen (aktuell „Preise individuell“)

Hosting: einfach den Ordnerinhalt auf den Webspace hochladen (z. B. IONOS) – kein Build nötig.
